# Магнит-бот

Личный Telegram-бот для сборки корзины в «Магните». Он берёт товары и готовые корзины из локального YAML-файла, находит их в каталоге и формирует корзину. Перед оплатой пользователь проверяет товары и оформляет заказ самостоятельно.

> Бот перед сборкой выбранной корзины очищает текущую корзину «Магнита». Не запускайте сборку, если в ней есть товары, которые нужно сохранить.

## Возможности

- обычные списки продуктов с количеством, обязательными словами, исключениями и заменами;
- именованные корзины: например, варианты завтраков с выбором одного или нескольких товаров из группы;
- два способа сборки: через сайт (Playwright) и API экспресс-доставки;
- интерфейс Telegram для запуска сборки и редактирования продуктов;
- локальный веб-редактор YAML-конфигурации;
- проверка наличия, итоговой цены и минимальной суммы заказа после сборки.

## Требования

- Windows 10/11;
- Python 3.11 или новее;
- установленный Google Chrome;
- [Ollama](https://ollama.com/) с моделью `qwen3:8b` и запущенным локальным сервером на порту `11434`;
- аккаунт «Магнита» с настроенной доставкой;
- личный Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

## Первый запуск

Откройте PowerShell в папке проекта:

```powershell
cd path\to\Magnit-bot
```

Создайте виртуальное окружение, установите зависимости и скопируйте пример настроек:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item magnit-products.example.yaml magnit-products.yaml
```

Откройте `magnit-products.yaml` и укажите адрес в поле `address` ровно так, как он показан в шапке сайта «Магнита». Добавьте продукты или готовые корзины. Этот файл не попадает в Git: в нём может быть ваш адрес и личные предпочтения.

Запустите Ollama и загрузите модель:

```powershell
ollama pull qwen3:8b
ollama serve
```

Если Ollama установлен как приложение Windows и уже работает в фоне, вторую команду выполнять не нужно.

### Вход в «Магнит»

Откройте изолированный профиль Chrome:

```powershell
.\.venv\Scripts\python.exe -m magnit_browser
```

В открывшемся Chrome войдите в «Магнит», выберите режим **«Доставка»**, нужный адрес и нажмите **«Подтвердить»**. Закройте окно Chrome. Сессия сохранится локально в `magnit-chrome-profile` и не публикуется в Git.

### Подключение Telegram

Создайте бота через [@BotFather](https://t.me/BotFather), затем выполните:

```powershell
.\.venv\Scripts\python.exe -m telegram_setup
```

Вставьте токен в скрытое приглашение терминала. Затем откройте ссылку, которую покажет программа, отправьте боту предложенный код и нажмите Enter в PowerShell. Токен и ID личного чата сохраняются в зашифрованном для текущей учётной записи Windows файле `telegram-binding.dpapi`.

## Ежедневный запуск

Убедитесь, что Ollama работает, затем выполните:

```powershell
cd path\to\Magnit-bot
.\.venv\Scripts\python.exe -m telegram_setup
```

Откройте Telegram, отправьте боту `/start`, нажмите **«Собрать корзину»**, выберите категорию и корзину. Не закрывайте окно PowerShell, пока бот должен принимать команды. Для остановки нажмите `Ctrl+C`.

Если истекла сессия «Магнита», снова выполните `python -m magnit_browser`. Если меняете токен или привязанный личный чат, используйте:

```powershell
.\.venv\Scripts\python.exe -m telegram_setup --rebind
```

## Редактор корзин

Чтобы редактировать готовые корзины и фотографии через браузер:

```powershell
.\.venv\Scripts\python.exe -m config_editor
```

Откройте http://127.0.0.1:8765/. Изменения сохраняются в `magnit-products.yaml`. Фотографии JPG и PNG размером до 10 МБ положите в папку `photos/` и укажите путь в поле `photo`.

## Конфигурация

`magnit-products.example.yaml` содержит минимальный пример. В рабочем `magnit-products.yaml`:

- `products` — отдельные позиции; `quantity` задаёт число упаковок;
- `required` — слова, которые должны быть в названии товара;
- `exclude` — слова или фразы, которых в названии быть не должно;
- `replacements` — ID запасных вариантов в порядке подбора;
- `baskets` — готовые корзины; в `groups.options` задаются товары по `sku`;
- `pick` — число разных вариантов, которое нужно выбрать из группы;
- `strategy: random` перемешивает варианты, `ordered` проверяет их по порядку;
- `backend` — `playwright` или `api`. API рассчитан на экспресс-доставку и использует текущую Chrome-сессию.

При работе через API дождитесь результата сборки, прежде чем менять корзину с телефона. Если API «Магнита» отклонит запрос, переключите backend на `playwright` и повторите сборку.

## Безопасность и ограничения

- Не публикуйте `magnit-products.yaml`, `telegram-binding.dpapi` или папку `magnit-chrome-profile`.
- Бот предназначен для личного использования и зависит от текущего интерфейса и API «Магнита».
- Перед оплатой всегда проверяйте состав корзины, наличие товаров, стоимость и адрес доставки.
