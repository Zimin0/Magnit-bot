# Автоматический контекст браузера для Magnit CLI

## Намерение

При запуске Telegram-бота автоматически получать актуальный контекст доставки из сохранённого Chrome-профиля и передавать его каждому subprocess `magnit-cli`. Пользователь не должен вручную задавать `MAGNIT_DEVICE_ID`, JWT, магазин или адрес.

## Границы

- Контекст считывается только из реального GET-запроса корзины `magnit.ru` в существующем профиле `magnit-chrome-profile`.
- Браузер запускается headless один раз при старте бота и закрывается до начала Telegram polling.
- Значения заголовков хранятся только в памяти текущего процесса, не пишутся в YAML, логи, Telegram или Git.
- `MAGNIT_CLI_DIR` остаётся явной локальной настройкой пути к CLI.
- Если вход, доставка, адрес или обязательные заголовки не подтверждены, бот останавливается до любых изменений корзины с понятной ошибкой.

## Подходы

1. **Выбранный:** получать свежий контекст при каждом запуске через headless Chrome. Токены не сохраняются и не устаревают между запусками; цена — несколько секунд запуска.
2. Хранить перехваченный контекст через Windows DPAPI. Быстрее при запуске, но добавляет секретное состояние и риск использовать устаревший JWT, магазин или адрес.
3. Отказаться от CLI и выполнять корзину через существующий `MagnitApiStore`. Не подходит, потому что требование проекта — выполнение Qwen-заказов через `magnit-cli`.

## Поток

1. `telegram_setup` открывает профиль через `open_profile(headless=True)`.
2. Общий компонент наблюдает GET `/webgate/v1/carts/lite`, проверяет вход и выбранный адрес, извлекает allowlist заголовков CLI.
3. Компонент требует стабильный `X-Device-Id`, а также контекст авторизации, магазина, сервиса и адреса, необходимый для корзины и checkout.
4. `MagnitCli` получает отдельный словарь окружения и добавляет только разрешённые `MAGNIT_*` значения к окружению каждого subprocess.
5. Все команды `cart`, `cart-set` и `checkout-preview` используют один и тот же снимок контекста.

## Проверка

- Тест: два последовательных вызова CLI получают одинаковый `MAGNIT_DEVICE_ID` и остальные значения.
- Тест: секретные значения не появляются в исключениях и логах.
- Тест: неполный или неподтверждённый браузерный контекст останавливает запуск до polling и `cart-set`.
- Тест: успешный запуск передаёт полученный контекст в единственный экземпляр `MagnitCli` и затем запускает polling.
- Полный набор тестов приложения.
- Живая безопасная проверка: два последовательных чтения `cart` возвращают один cart ID; изменение корзины выполняется только после нового подтверждения пользователя в Telegram.
